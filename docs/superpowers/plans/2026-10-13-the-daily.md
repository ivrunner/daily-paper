# The Daily Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build "The Daily", a static newspaper-style website built every morning from RSS feeds by GitHub Actions and hosted on GitHub Pages.

**Architecture:** A small Python package runs one pipeline: `fetch` (download feeds) → `clean` (normalize and remove duplicates) → `edition` (rules pick the lead, section order, front-page slots and ticker) → `render` (Jinja2 templates plus one CSS theme produce static HTML). Each edition is saved as JSON in `editions/`, which is committed every day, so the last 30 days of pages are redrawn on every build. A scheduled GitHub Actions workflow runs the build at 5 AM Eastern and deploys `site/` to Pages.

**Tech Stack:** Python 3.11+ (3.12 in CI), feedparser, requests, Jinja2, PyYAML, pytest. Plain HTML and CSS with Google Fonts. GitHub Actions and GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-10-13-the-daily-design.md`. Approved visual references are `docs/mockups/front-page.html` and `docs/mockups/section-page.html`.

## Global Constraints

- Paper is named **The Daily**; tagline is exactly `Tech · Sport · Fiber · Play`.
- Builds run at 5:00 AM America/New_York. Timestamps are stored in UTC and displayed in ET with the suffix `ET`.
- Weather: Fort Wayne, IN 46845, lat 41.17, lon −85.10, Open-Meteo, Fahrenheit.
- Rules-only selection, with no AI and no API keys. Running cost is $0.
- Time window is 24 hours, or 48 hours when a section has fewer than 4 articles. Each section keeps at most 12 articles and at most 5 per source.
- Duplicates: links match after removing tracking parameters, or titles have Jaccard similarity ≥ 0.6. Story groups share ≥ 3 meaningful title words.
- Summaries are cut to 60 words. Every story links out to the source, and no full article text is copied.
- Keep 30 days of editions. The build fails, without deploying, if every feed fails or the edition has fewer than 10 stories.
- Colors: paper `#f1ede4`, ink `#1d1b18`, muted `#57524a`, accent `#d9661b`, sage `#e3e6cf`. Grain opacity is `.28`.
- Fonts: DM Serif Display, Source Serif 4, Space Grotesk, Bodoni Moda, all from Google Fonts.
- Breakpoints: ≥1024 full grid, 768–1023 tablet, <768 phone.
- Every link inside the site is relative, so the site works under `/daily-paper/` and from `file://`.
- The repo is public, and no secrets are stored in it.

## Review Focus

1. **Feed images that aren't article photos.** WordPress feeds embed Gravatar author avatars, and FeedBurner adds 1×1 tracking pixels. The expected behavior is to skip these and show a text-only card. Pinned in Task 2 (`test_find_image_skips_trackers_and_avatars`).
2. **Photos that fail to load in Safari** because of hotlink protection or a 404. The expected behavior is that the card falls back to text-only, with no broken-image icon. Pinned in Task 7 (`test_photos_have_fallback_and_no_referrer`).
3. **One big story covered across sections.** For example, an Apple launch shows up in Technology and in Apple. It should appear once on the front page as the lead, not as the lead plus a repeat in the Technology slot. Pinned in Task 6 (`test_lead_story_not_repeated_on_front_page`).
4. **A typo made while editing `feeds.yaml` on a phone** (a missing slug, a duplicate slug, or a reserved slug such as `static`). The expected behavior is a clear error that names the problem, not a stack trace or a broken site. Pinned in Task 4 (`test_load_config_rejects_bad_slugs`).
5. **Nonstandard or future publish dates.** Fierce Network uses `Oct 13, 2026 6:57pm`, and some feeds give future-dated posts. These must not take over the "newest" ordering. Pinned in Task 2 (`test_parse_published_fallback_format_and_future_clamp`).

```python
from __future__ import annotations

import re
from datetime import datetime, timedelta, timezone

from paper.models import Article

NOW = datetime(2026, 10, 13, 9, 0, tzinfo=timezone.utc)  # 5:00 AM EDT


def _slug(text: str) -> str:
    return re.sub(r"[^a-z0-9]+", "-", text.lower()).strip("-")


def make_entry(title: str, link: str, *, hours_ago: float = 1.0, image: str | None = None,
               summary: str = "A short summary of the story.") -> dict:
    """A dict shaped like a feedparser entry."""
    entry = {
        "title": title,
        "link": link,
        "summary": summary,
        "published_parsed": (NOW - timedelta(hours=hours_ago)).utctimetuple(),
    }
    if image:
        entry["media_content"] = [{"url": image, "medium": "image"}]
    return entry


def make_article(title: str, *, source: str = "Source", section: str = "tech",
                 hours_ago: float = 1.0, image: str | None = None, link: str | None = None,
                 also: list[str] | None = None) -> Article:
    return Article(
        title=title,
        link=link or f"https://{_slug(source)}.example/{_slug(title)}",
        summary=f"Summary of {title}.",
        source=source,
        section_slug=section,
        published=NOW - timedelta(hours=hours_ago),
        image_url=image,
        also_covered_by=list(also or []),
    )
```

```python
"""Data types shared by every step of the build."""
from __future__ import annotations

from dataclasses import asdict, dataclass, field
from datetime import date, datetime


@dataclass
class Article:
    title: str
    link: str
    summary: str
    source: str
    section_slug: str
    published: datetime  # timezone-aware, UTC
    image_url: str | None = None
    also_covered_by: list[str] = field(default_factory=list)

    def to_dict(self) -> dict:
        data = asdict(self)
        data["published"] = self.published.isoformat()
        return data

    @classmethod
    def from_dict(cls, data: dict) -> Article:
        return cls(**{**data, "published": datetime.fromisoformat(data["published"])})


@dataclass
class Weather:
    place: str
    high_f: int
    low_f: int
    label: str
    icon: str  # one of: sun, partly, cloud, fog, rain, snow, storm

    def to_dict(self) -> dict:
        return asdict(self)

    @classmethod
    def from_dict(cls, data: dict) -> Weather:
        return cls(**data)


@dataclass
class Quote:
    text: str
    author: str


@dataclass
class Section:
    number: int
    name: str
    slug: str
    articles: list[Article]  # articles[0] is the section's top story

    @property
    def top(self) -> Article | None:
        return self.articles[0] if self.articles else None

    @property
    def sources(self) -> list[str]:
        return sorted({a.source for a in self.articles})


@dataclass
class Edition:
    date: date
    built_at: datetime  # timezone-aware, America/New_York
    volume: int
    issue: int
    lead: Article | None
    front: list[Article]
    sections: list[Section]
    ticker: list[Article]
    quote: Quote | None
    weather: Weather | None

    @property
    def story_count(self) -> int:
        return sum(len(s.articles) for s in self.sections)

    @property
    def source_count(self) -> int:
        return len({a.source for s in self.sections for a in s.articles})

    def to_dict(self) -> dict:
        return {
            "date": self.date.isoformat(),
            "built_at": self.built_at.isoformat(),
            "volume": self.volume,
            "issue": self.issue,
            "lead": self.lead.to_dict() if self.lead else None,
            "front": [a.to_dict() for a in self.front],
            "sections": [
                {"number": s.number, "name": s.name, "slug": s.slug,
                 "articles": [a.to_dict() for a in s.articles]}
                for s in self.sections
            ],
            "ticker": [a.to_dict() for a in self.ticker],
            "quote": asdict(self.quote) if self.quote else None,
            "weather": self.weather.to_dict() if self.weather else None,
        }

    @classmethod
    def from_dict(cls, data: dict) -> Edition:
        return cls(
            date=date.fromisoformat(data["date"]),
            built_at=datetime.fromisoformat(data["built_at"]),
            volume=data["volume"],
            issue=data["issue"],
            lead=Article.from_dict(data["lead"]) if data["lead"] else None,
            front=[Article.from_dict(a) for a in data["front"]],
            sections=[
                Section(number=s["number"], name=s["name"], slug=s["slug"],
                        articles=[Article.from_dict(a) for a in s["articles"]])
                for s in data["sections"]
            ],
            ticker=[Article.from_dict(a) for a in data["ticker"]],
            quote=Quote(**data["quote"]) if data["quote"] else None,
            weather=Weather.from_dict(data["weather"]) if data["weather"] else None,
        )
```

```python
"""Turn raw feed entries into clean Article objects, and remove duplicates."""
from __future__ import annotations

import html
import re
from datetime import datetime, timezone
from urllib.parse import parse_qsl, urlencode, urlsplit, urlunsplit
from zoneinfo import ZoneInfo

from paper.models import Article

SUMMARY_WORDS = 60
DUPLICATE_SIMILARITY = 0.6
ET = ZoneInfo("America/New_York")
STOPWORDS = frozenset("""
a about after all an and are as at be been but by can could did do does for from get gets had has have
he her his how i if in into is it its just more new not now of off on or our out over says she so than
that the their them they this to up us was we were what when where which who why will with would you your
""".split())
TRACKING_KEYS = frozenset({"fbclid", "gclid", "mc_cid", "mc_eid", "cmpid", "ref", "guccounter", "src"})
IMAGE_EXTENSIONS = (".jpg", ".jpeg", ".png", ".webp", ".gif", ".avif")
NOT_PHOTOS = ("feedburner.com", "gravatar.com", "doubleclick.net", "stats.wp.com", "pixel")
FALLBACK_DATE_FORMATS = ("%b %d, %Y %I:%M%p",)  # "Oct 13, 2026 6:57pm" (Fierce Network, Eastern)
_IMG_SRC = re.compile(r"""<img[^>]+src=["']([^"']+)["']""", re.I)


def strip_html(text: str | None) -> str:
    text = re.sub(r"<(script|style)\b.*?</\1>", " ", text or "", flags=re.S | re.I)
    text = re.sub(r"<[^>]+>", " ", text)
    text = html.unescape(text)
    return re.sub(r"\s+", " ", text).strip()


def truncate_words(text: str, limit: int = SUMMARY_WORDS) -> str:
    words = text.split()
    if len(words) <= limit:
        return text
    return " ".join(words[:limit]).rstrip(",;:.-") + "…"


def normalize_url(url: str) -> str:
    """Comparable form of a link: no scheme, no www, no tracking params, no trailing slash."""
    parts = urlsplit(url.strip())
    query = [(k, v) for k, v in parse_qsl(parts.query, keep_blank_values=True)
             if not k.lower().startswith("utm_") and k.lower() not in TRACKING_KEYS]
    host = parts.netloc.lower().removeprefix("www.")
    return urlunsplit(("", host, parts.path.rstrip("/"), urlencode(query), "")).lstrip("/")


def title_words(title: str) -> set[str]:
    text = title.lower().replace("’", "'").replace("'s", "")
    return {w for w in re.findall(r"[a-z0-9]+", text) if w not in STOPWORDS and len(w) > 1}


def similarity(a: set[str], b: set[str]) -> float:
    if not a or not b:
        return 0.0
    return len(a & b) / len(a | b)


def _looks_like_image(url: str) -> bool:
    return urlsplit(url).path.lower().endswith(IMAGE_EXTENSIONS)


def find_image(entry) -> str | None:
    candidates: list[str] = []
    for media in entry.get("media_content") or []:
        url = media.get("url", "")
        if media.get("medium") == "image" or (media.get("type") or "").startswith("image/") or _looks_like_image(url):
            candidates.append(url)
    candidates += [t.get("url", "") for t in entry.get("media_thumbnail") or []]
    for link in [*(entry.get("enclosures") or []), *(entry.get("links") or [])]:
        if (link.get("type") or "").startswith("image/"):
            candidates.append(link.get("href", ""))
    for block in entry.get("content") or []:
        candidates += _IMG_SRC.findall(block.get("value", ""))
    candidates += _IMG_SRC.findall(entry.get("summary") or "")
    for url in candidates:
        url = html.unescape(url.strip())
        if url.startswith("//"):
            url = "https:" + url
        if url.startswith(("http://", "https://")) and not any(bad in url for bad in NOT_PHOTOS):
            return url
    return None


def parse_published(entry, fallback: datetime) -> datetime:
    """Publish time in UTC; never later than `fallback` (the fetch time)."""
    for key in ("published_parsed", "updated_parsed"):
        parsed = entry.get(key)
        if parsed:
            return min(datetime(*parsed[:6], tzinfo=timezone.utc), fallback)
    raw = (entry.get("published") or entry.get("updated") or "").strip()
    for fmt in FALLBACK_DATE_FORMATS:
        try:
            local = datetime.strptime(raw, fmt).replace(tzinfo=ET)
        except ValueError:
            continue
        return min(local.astimezone(timezone.utc), fallback)
    return fallback


def entry_to_article(entry, *, source: str, section_slug: str, fetched_at: datetime) -> Article | None:
    title = strip_html(entry.get("title"))
    link = (entry.get("link") or "").strip()
    if not title or not link.startswith(("http://", "https://")):
        return None
    summary_html = entry.get("summary") or ""
    if not summary_html and entry.get("content"):
        summary_html = entry["content"][0].get("value", "")
    summary = truncate_words(strip_html(summary_html))
    if summary.lower() == title.lower():
        summary = ""
    return Article(
        title=title, link=link, summary=summary, source=source, section_slug=section_slug,
        published=parse_published(entry, fallback=fetched_at), image_url=find_image(entry),
    )
```

```python
def _same_story(a: Article, b: Article) -> bool:
    return (normalize_url(a.link) == normalize_url(b.link)
            or similarity(title_words(a.title), title_words(b.title)) >= DUPLICATE_SIMILARITY)


def _merge(kept: Article, dup: Article) -> Article:
    winner = dup if kept.image_url is None and dup.image_url else kept
    sources: list[str] = []
    for name in [kept.source, *kept.also_covered_by, dup.source, *dup.also_covered_by]:
        if name != winner.source and name not in sources:
            sources.append(name)
    winner.also_covered_by = sources
    return winner


def dedupe(articles: list[Article]) -> list[Article]:
    kept: list[Article] = []
    for article in sorted(articles, key=lambda a: a.published, reverse=True):
        for i, existing in enumerate(kept):
            if _same_story(existing, article):
                kept[i] = _merge(existing, article)
                break
        else:
            kept.append(article)
    return kept
```

```python
"""Read feeds.yaml and download every feed in parallel."""
from __future__ import annotations

import re
from concurrent.futures import ThreadPoolExecutor
from dataclasses import dataclass
from pathlib import Path

import feedparser
import requests
import yaml

TIMEOUT = 15
USER_AGENT = ("Mozilla/5.0 (Macintosh; Intel Mac OS X 14_0) AppleWebKit/605.1.15 "
              "(KHTML, like Gecko) Version/17.0 Safari/605.1.15 TheDaily/1.0")
RESERVED_SLUGS = frozenset({"static", "archive", "editions"})


class ConfigError(ValueError):
    """feeds.yaml is malformed. The message says what to fix."""


@dataclass
class FeedSpec:
    name: str
    url: str
    section_slug: str


@dataclass
class SectionSpec:
    number: int
    name: str
    slug: str
    feeds: list[FeedSpec]


@dataclass
class FeedResult:
    feed: FeedSpec
    entries: list
    error: str | None


def load_config(path: Path) -> list[SectionSpec]:
    data = yaml.safe_load(Path(path).read_text(encoding="utf-8")) or {}
    if not isinstance(data, dict) or not isinstance(data.get("sections"), list):
        raise ConfigError("feeds.yaml needs a top-level 'sections' list")
    sections: list[SectionSpec] = []
    seen: set[str] = set()
    for number, raw in enumerate(data["sections"], start=1):
        name = (raw or {}).get("name") or f"section {number}"
        slug = (raw or {}).get("slug")
        if not slug:
            raise ConfigError(f"Section '{name}' is missing 'slug'")
        slug = str(slug)
        if not re.fullmatch(r"[a-z0-9-]+", slug):
            raise ConfigError(f"Section '{name}': slug '{slug}' may only use a-z, 0-9 and '-'")
        if slug in RESERVED_SLUGS:
            raise ConfigError(f"Section '{name}': slug '{slug}' is reserved")
        if slug in seen:
            raise ConfigError(f"Slug '{slug}' is used twice")
        seen.add(slug)
        feeds = []
        for feed in raw.get("feeds") or []:
            if not isinstance(feed, dict) or not feed.get("name") or not feed.get("url"):
                raise ConfigError(f"A feed in section '{name}' needs a name and url")
            feeds.append(FeedSpec(name=str(feed["name"]), url=str(feed["url"]), section_slug=slug))
        sections.append(SectionSpec(number=number, name=str(name), slug=slug, feeds=feeds))
    return sections


def fetch_feed(feed: FeedSpec) -> FeedResult:
    try:
        response = requests.get(feed.url, headers={"User-Agent": USER_AGENT}, timeout=TIMEOUT)
        response.raise_for_status()
        parsed = feedparser.parse(response.content)
    except Exception as exc:  # any failure only skips this one feed
        return FeedResult(feed, [], f"{type(exc).__name__}: {exc}")
    if not parsed.entries:
        return FeedResult(feed, [], "no entries")
    return FeedResult(feed, list(parsed.entries), None)


def fetch_all(sections: list[SectionSpec], max_workers: int = 12) -> list[FeedResult]:
    feeds = [feed for section in sections for feed in section.feeds]
    with ThreadPoolExecutor(max_workers=max_workers) as pool:
        return list(pool.map(fetch_feed, feeds))
```

```python
"""Today's forecast for the masthead weather box (Open-Meteo, free, no key)."""
from __future__ import annotations

import logging

import requests

from paper.models import Weather

URL = "https://api.open-meteo.com/v1/forecast"
log = logging.getLogger(__name__)

# WMO weather codes → (label, icon)
CODES: list[tuple[tuple[int, ...], str, str]] = [
    ((0,), "Clear", "sun"),
    ((1, 2), "Partly cloudy", "partly"),
    ((3,), "Overcast", "cloud"),
    ((45, 48), "Fog", "fog"),
    ((51, 53, 55, 56, 57), "Drizzle", "rain"),
    ((61, 63, 65, 66, 67, 80, 81, 82), "Rain", "rain"),
    ((71, 73, 75, 77, 85, 86), "Snow", "snow"),
    ((95, 96, 99), "Thunderstorms", "storm"),
]


def describe(code: int) -> tuple[str, str]:
    for codes, label, icon in CODES:
        if code in codes:
            return label, icon
    return "Cloudy", "cloud"


def parse_forecast(data: dict, place: str) -> Weather:
    daily = data["daily"]
    label, icon = describe(int(daily["weather_code"][0]))
    return Weather(place=place, high_f=round(daily["temperature_2m_max"][0]),
                   low_f=round(daily["temperature_2m_min"][0]), label=label, icon=icon)


def get_weather(place: str = "Fort Wayne", lat: float = 41.17, lon: float = -85.10) -> Weather | None:
    params = {
        "latitude": lat, "longitude": lon,
        "daily": "weather_code,temperature_2m_max,temperature_2m_min",
        "temperature_unit": "fahrenheit", "timezone": "America/New_York", "forecast_days": 1,
    }
    try:
        response = requests.get(URL, params=params, timeout=10)
        response.raise_for_status()
        return parse_forecast(response.json(), place)
    except Exception as exc:  # weather is optional; the box is simply left out
        log.warning("Weather unavailable: %s", exc)
        return None
```

```python
"""The editor's rules: what's in the paper today and where it goes."""
from __future__ import annotations

import dataclasses
from collections import Counter
from datetime import date, datetime, timedelta
from zoneinfo import ZoneInfo

from paper.clean import title_words
from paper.fetch import SectionSpec
from paper.models import Article, Edition, Quote, Section, Weather

ET = ZoneInfo("America/New_York")
MAX_PER_SECTION = 12
MAX_PER_SOURCE = 5
MIN_PER_SECTION = 4
GROUP_MIN_SHARED_WORDS = 3
FRONT_SLOTS = 6
TICKER_PER_SECTION = 2


def _cap(items: list[Article]) -> list[Article]:
    per_source: Counter[str] = Counter()
    kept: list[Article] = []
    for article in items:
        if per_source[article.source] >= MAX_PER_SOURCE:
            continue
        per_source[article.source] += 1
        kept.append(article)
        if len(kept) == MAX_PER_SECTION:
            break
    return kept


def select_window(articles: list[Article], slugs: list[str], now: datetime) -> dict[str, list[Article]]:
    by_section: dict[str, list[Article]] = {slug: [] for slug in slugs}
    for article in sorted(articles, key=lambda a: a.published, reverse=True):
        if article.section_slug in by_section:
            by_section[article.section_slug].append(article)
    window = {}
    for slug, items in by_section.items():
        recent = [a for a in items if a.published >= now - timedelta(hours=24)]
        if len(recent) < MIN_PER_SECTION:
            recent = [a for a in items if a.published >= now - timedelta(hours=48)]
        window[slug] = _cap(recent)
    return window


def _related(a: Article, b: Article) -> bool:
    return len(title_words(a.title) & title_words(b.title)) >= GROUP_MIN_SHARED_WORDS


def group_stories(articles: list[Article]) -> list[list[Article]]:
    groups: list[list[Article]] = []
    for article in articles:
        for members in groups:
            if any(_related(article, m) for m in members):
                members.append(article)
                break
        else:
            groups.append([article])
    return groups


def _coverage(group: list[Article]) -> list[str]:
    sources: list[str] = []
    for article in group:
        for name in [article.source, *article.also_covered_by]:
            if name not in sources:
                sources.append(name)
    return sources


def _newest(articles: list[Article]) -> Article:
    with_image = [a for a in articles if a.image_url]
    return max(with_image or articles, key=lambda a: a.published)


def pick_top(articles: list[Article]) -> Article | None:
    """The story most sources are covering, else the newest story with a photo."""
    if not articles:
        return None
    best = max(group_stories(articles), key=lambda g: (len(_coverage(g)), max(a.published for a in g)))
    sources = _coverage(best)
    if len(sources) >= 2:
        rep = _newest(best)
        return dataclasses.replace(rep, also_covered_by=[s for s in sources if s != rep.source])
    return _newest(articles)


def _order(articles: list[Article], top: Article | None) -> list[Article]:
    if top is None:
        return []
    return [top] + [a for a in articles if a.link != top.link]


def _front_slots(sections: list[Section], lead: Article | None) -> list[Article]:
    others = [s for s in sections if not (lead and s.slug == lead.section_slug)]
    front = [s.articles[0] for s in others if s.articles]
    for s in others:  # an empty section's slot goes to another section's next story
        if len(front) >= FRONT_SLOTS:
            break
        if len(s.articles) > 1:
            front.append(s.articles[1])
    return front[:FRONT_SLOTS]


def parse_quotes(text: str) -> list[Quote]:
    quotes = []
    for line in text.splitlines():
        line = line.strip()
        if not line or line.startswith("#") or " — " not in line:
            continue
        body, author = line.rsplit(" — ", 1)
        quotes.append(Quote(text=body.strip().strip('"“”'), author=author.strip()))
    return quotes


def quote_for(day: date, quotes: list[Quote]) -> Quote | None:
    return quotes[day.timetuple().tm_yday % len(quotes)] if quotes else None


def volume_and_issue(day: date, launch: date) -> tuple[int, int]:
    years = day.year - launch.year - ((day.month, day.day) < (launch.month, launch.day))
    return years + 1, (day - launch).days + 1


def build_edition(articles: list[Article], *, sections: list[SectionSpec], now: datetime, launch: date,
                  quotes: list[Quote], weather: Weather | None) -> Edition:
    window = select_window(articles, [s.slug for s in sections], now)
    lead = pick_top([a for items in window.values() for a in items])
    built: list[Section] = []
    for spec in sections:
        items = window[spec.slug]
        if lead and spec.slug == lead.section_slug:
            top = lead
        else:
            candidates = [a for a in items if not (lead and _related(a, lead))] or items
            top = pick_top(candidates)
        built.append(Section(number=spec.number, name=spec.name, slug=spec.slug, articles=_order(items, top)))
    front = _front_slots(built, lead)
    used = {a.link for a in front} | ({lead.link} if lead else set())
    ticker = []
    for section in built:
        ticker += [a for a in section.articles if a.link not in used][:TICKER_PER_SECTION]
    local = now.astimezone(ET)
    volume, issue = volume_and_issue(local.date(), launch)
    return Edition(date=local.date(), built_at=local, volume=volume, issue=issue, lead=lead, front=front,
                   sections=built, ticker=ticker, quote=quote_for(local.date(), quotes), weather=weather)
```

```python
"""Generate the Home Screen icons (orange sun on newsprint) with the standard library only.

Run: python tools/make_icon.py
"""
from __future__ import annotations

import math
import struct
import zlib
from pathlib import Path

PAPER = (241, 237, 228)
ACCENT = (217, 102, 27)
STATIC = Path(__file__).resolve().parent.parent / "static"


def _inside_sun(x: float, y: float) -> bool:
    """Coordinates are in a 0..1 unit square."""
    dx, dy = x - 0.5, y - 0.5
    r = math.hypot(dx, dy)
    if r <= 0.19:
        return True
    if 0.27 <= r <= 0.40:
        angle = math.atan2(dy, dx) % (math.pi / 4)
        return min(angle, math.pi / 4 - angle) * r <= 0.024
    return False


def render(size: int, samples: int = 3) -> bytes:
    rows = []
    for py in range(size):
        row = bytearray([0])  # PNG filter type 0
        for px in range(size):
            hits = sum(_inside_sun((px + (sx + .5) / samples) / size, (py + (sy + .5) / samples) / size)
                       for sx in range(samples) for sy in range(samples))
            t = hits / samples ** 2
            row += bytes(round(p + (a - p) * t) for p, a in zip(PAPER, ACCENT))
        rows.append(bytes(row))

    def chunk(tag: bytes, data: bytes) -> bytes:
        return struct.pack(">I", len(data)) + tag + data + struct.pack(">I", zlib.crc32(tag + data) & 0xFFFFFFFF)

    header = struct.pack(">IIBBBBB", size, size, 8, 2, 0, 0, 0)
    return (b"\x89PNG\r\n\x1a\n" + chunk(b"IHDR", header) + chunk(b"IDAT", zlib.compress(b"".join(rows), 9))
            + chunk(b"IEND", b""))


if __name__ == "__main__":
    STATIC.mkdir(exist_ok=True)
    (STATIC / "apple-touch-icon.png").write_bytes(render(180))
    (STATIC / "icon-512.png").write_bytes(render(512))
    print("wrote static/apple-touch-icon.png and static/icon-512.png")
```

```python
"""Turn editions into the static website."""
from __future__ import annotations

import os
import shutil
from pathlib import Path

from jinja2 import Environment, FileSystemLoader, StrictUndefined, select_autoescape

from paper.clean import truncate_words
from paper.models import Edition

ROOT = Path(__file__).resolve().parent.parent
TEMPLATES = ROOT / "templates"
STATIC = ROOT / "static"
MARKER = ".the-daily-site"


def make_env() -> Environment:
    env = Environment(loader=FileSystemLoader(TEMPLATES), autoescape=select_autoescape(["html"]),
                      undefined=StrictUndefined, trim_blocks=True, lstrip_blocks=True)
    env.filters["longdate"] = lambda d: f"{d:%A}, {d:%B} {d.day}, {d.year}"
    env.filters["shortdate"] = lambda d: f"{d:%b} {d.day}"
    env.filters["clock"] = lambda dt: f"{dt:%I:%M %p}".lstrip("0") + " ET"
    env.filters["words"] = truncate_words
    return env


def _prefix(target: Path, page_dir: Path) -> str:
    """Relative path from page_dir to target, with a trailing slash ('' when they're the same)."""
    rel = os.path.relpath(target, page_dir)
    return "" if rel == "." else rel.replace(os.sep, "/") + "/"


def _write(env: Environment, template: str, page_dir: Path, site_dir: Path, home_dir: Path, **context) -> None:
    page_dir.mkdir(parents=True, exist_ok=True)
    html = env.get_template(template).render(root=_prefix(site_dir, page_dir), home=_prefix(home_dir, page_dir),
                                             **context)
    (page_dir / "index.html").write_text(html, encoding="utf-8")


def render_edition(env: Environment, edition: Edition, edition_dir: Path, site_dir: Path, *, is_today: bool) -> None:
    names = {s.slug: s.name for s in edition.sections}
    common = {"edition": edition, "names": names, "is_today": is_today}
    _write(env, "front.html", edition_dir, site_dir, edition_dir, **common)
    for i, section in enumerate(edition.sections):
        prev = edition.sections[i - 1] if i > 0 else None
        nxt = edition.sections[i + 1] if i + 1 < len(edition.sections) else None
        _write(env, "section.html", edition_dir / section.slug, site_dir, edition_dir,
               section=section, prev=prev, next=nxt, **common)


def _reset(site_dir: Path) -> None:
    if site_dir.exists():
        if any(site_dir.iterdir()) and not (site_dir / MARKER).exists():
            raise ValueError(f"Refusing to clear {site_dir}: it isn't a folder The Daily built")
        shutil.rmtree(site_dir)
    site_dir.mkdir(parents=True)
    (site_dir / MARKER).write_text("Built by paper.render; safe to delete.\n")


def render_site(editions: list[Edition], site_dir: Path) -> None:
    """editions are newest first. Today's goes at the root; every edition also lives under editions/<date>/."""
    site_dir = Path(site_dir)
    _reset(site_dir)
    shutil.copytree(STATIC, site_dir / "static")
    env = make_env()
    if editions:
        render_edition(env, editions[0], site_dir, site_dir, is_today=True)
    for edition in editions:
        render_edition(env, edition, site_dir / "editions" / edition.date.isoformat(), site_dir, is_today=False)
    _write(env, "archive.html", site_dir / "archive", site_dir, site_dir, editions=editions)
```

```python
"""Build today's edition and the whole site.

Run:  python -m paper.build            (writes site/)
      python -m paper.build --out /tmp/preview
"""
from __future__ import annotations

import argparse
import json
import logging
import os
from datetime import date, datetime, timedelta, timezone
from pathlib import Path

from paper.clean import dedupe, entry_to_article
from paper.edition import ET, build_edition, parse_quotes
from paper.fetch import ConfigError, FeedResult, fetch_all, load_config
from paper.models import Article, Edition
from paper.render import render_site
from paper.weather import get_weather

ROOT = Path(__file__).resolve().parent.parent
KEEP_DAYS = 30
MIN_STORIES = 10
log = logging.getLogger("paper")


def collect_articles(results: list[FeedResult], fetched_at: datetime) -> list[Article]:
    articles = []
    for result in results:
        for entry in result.entries:
            article = entry_to_article(entry, source=result.feed.name, section_slug=result.feed.section_slug,
                                       fetched_at=fetched_at)
            if article:
                articles.append(article)
    return dedupe(articles)


def _edition_dates(editions_dir: Path) -> list[date]:
    dates = []
    for path in editions_dir.glob("*.json"):
        try:
            dates.append(date.fromisoformat(path.stem))
        except ValueError:
            continue
    return dates


def load_editions(editions_dir: Path) -> list[Edition]:
    editions = []
    for day in sorted(_edition_dates(editions_dir), reverse=True):
        path = editions_dir / f"{day.isoformat()}.json"
        try:
            editions.append(Edition.from_dict(json.loads(path.read_text(encoding="utf-8"))))
        except (ValueError, KeyError, TypeError) as exc:
            log.warning("Skipping unreadable edition %s: %s", path.name, exc)
    return editions


def prune_editions(editions_dir: Path, today: date, keep_days: int = KEEP_DAYS) -> None:
    cutoff = today - timedelta(days=keep_days - 1)
    for day in _edition_dates(editions_dir):
        if day < cutoff:
            (editions_dir / f"{day.isoformat()}.json").unlink()


def write_report(results: list[FeedResult], edition: Edition | None, problem: str | None) -> None:
    failed = [r for r in results if r.error]
    lines = ["## The Daily: build report", ""]
    if problem:
        lines += [f"**Not published:** {problem}", ""]
    if edition:
        lines += [f"Edition {edition.date.isoformat()}: {edition.story_count} stories from "
                  f"{edition.source_count} sources.", ""]
    lines += [f"Feeds OK: {len(results) - len(failed)} / {len(results)}"]
    if failed:
        lines += ["", "| Section | Feed | Problem |", "|---|---|---|"]
        lines += [f"| {r.feed.section_slug} | {r.feed.name} | {r.error} |" for r in failed]
    text = "\n".join(lines) + "\n"
    print(text)
    summary = os.environ.get("GITHUB_STEP_SUMMARY")
    if summary:
        with open(summary, "a", encoding="utf-8") as fh:
            fh.write(text)


def run(*, out: Path, editions_dir: Path, config: Path, quotes_path: Path, now: datetime | None = None,
        fetcher=fetch_all, weather_fn=get_weather) -> int:
    now = now or datetime.now(timezone.utc)
    sections = load_config(config)
    results = fetcher(sections)
    if results and all(r.error for r in results):
        write_report(results, None, "every feed failed")
        return 1
    today = now.astimezone(ET).date()
    editions_dir.mkdir(parents=True, exist_ok=True)
    launch = min(_edition_dates(editions_dir) + [today])
    quotes = parse_quotes(quotes_path.read_text(encoding="utf-8")) if quotes_path.exists() else []
    edition = build_edition(collect_articles(results, now), sections=sections, now=now, launch=launch,
                            quotes=quotes, weather=weather_fn())
    if edition.story_count < MIN_STORIES:
        write_report(results, edition, f"only {edition.story_count} stories (need {MIN_STORIES})")
        return 1
    path = editions_dir / f"{edition.date.isoformat()}.json"
    path.write_text(json.dumps(edition.to_dict(), indent=1, ensure_ascii=False), encoding="utf-8")
    prune_editions(editions_dir, edition.date)
    render_site(load_editions(editions_dir), out)
    write_report(results, edition, None)
    return 0


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description="Build The Daily.")
    parser.add_argument("--out", type=Path, default=ROOT / "site")
    parser.add_argument("--editions", type=Path, default=ROOT / "editions")
    parser.add_argument("--config", type=Path, default=ROOT / "feeds.yaml")
    parser.add_argument("--quotes", type=Path, default=ROOT / "quotes.txt")
    args = parser.parse_args(argv)
    logging.basicConfig(level=logging.INFO, format="%(levelname)s %(message)s")
    try:
        return run(out=args.out, editions_dir=args.editions, config=args.config, quotes_path=args.quotes)
    except ConfigError as exc:
        log.error("feeds.yaml problem: %s", exc)
        return 1


if __name__ == "__main__":
    raise SystemExit(main())
```

```yaml
name: Daily edition

on:
  schedule:
    - cron: "0 9 * * *"    # 5 AM EDT / 4 AM EST
    - cron: "0 10 * * *"   # 6 AM EDT / 5 AM EST
  workflow_dispatch:

permissions:
  contents: write
  pages: write
  id-token: write

concurrency:
  group: daily-edition
  cancel-in-progress: false

jobs:
  build:
    runs-on: ubuntu-latest
    outputs:
      go: ${{ steps.gate.outputs.go }}
    steps:
      - uses: actions/checkout@v4

      - name: Time gate (5 AM Eastern, once a day)
        id: gate
        run: |
          TODAY=$(TZ=America/New_York date +%F)
          HOUR=$(TZ=America/New_York date +%H)
          echo "today=$TODAY" >> "$GITHUB_OUTPUT"
          if [ "${{ github.event_name }}" = "workflow_dispatch" ]; then
            echo "go=true" >> "$GITHUB_OUTPUT"
          elif { [ "$HOUR" = "05" ] || [ "$HOUR" = "06" ]; } && [ ! -f "editions/$TODAY.json" ]; then
            echo "go=true" >> "$GITHUB_OUTPUT"
          else
            echo "go=false" >> "$GITHUB_OUTPUT"
            echo "Skipping: hour $HOUR ET, or edition $TODAY already exists."
          fi

      - uses: actions/setup-python@v5
        if: steps.gate.outputs.go == 'true'
        with:
          python-version: "3.12"
          cache: pip

      - name: Install
        if: steps.gate.outputs.go == 'true'
        run: pip install -r requirements.txt

      - name: Build The Daily
        if: steps.gate.outputs.go == 'true'
        run: python -m paper.build --out site

      - name: Save edition
        if: steps.gate.outputs.go == 'true'
        run: |
          git config user.name "The Daily bot"
          git config user.email "41898282+github-actions[bot]@users.noreply.github.com"
          git add editions
          if ! git diff --cached --quiet; then
            git commit -m "Edition ${{ steps.gate.outputs.today }}"
            git pull --rebase
            git push
          fi

      - uses: actions/configure-pages@v5
        if: steps.gate.outputs.go == 'true'

      - uses: actions/upload-pages-artifact@v3
        if: steps.gate.outputs.go == 'true'
        with:
          path: site

  deploy:
    needs: build
    if: needs.build.outputs.go == 'true'
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - id: deployment
        uses: actions/deploy-pages@v4
```

Why the gate accepts 05 or 06: GitHub's scheduled runs can start late. With both hours accepted, the edition still gets built if the 5 AM run is delayed, and the "edition already exists" check stops a second build. If GitHub shows deprecation warnings for these action versions, bump them to the latest major version.
